# Proposed roadmap

This is an **idea backlog**, not a schedule, funding promise, or representation of work in progress.

| Phase | Potential milestone | Status |
| --- | --- | --- |
| 0 — Concept | Publish vision and local interactive mockup | Included in this repository |
| 1 — Validation | Interview buyers and merchants; test demand and risks | Not started |
| 2 — Design | Accessibility reviews, merchant flows, trust and safety designs | Not started |
| 3 — Prototype | Build authenticated demo with sandbox listings and APIs | Not started |
| 4 — Pilot | Invite real merchants after legal, payment, and security review | Not started |
| 5 — Scale | Evaluate integrations, payments, moderation, and operations | Not started |

## Gates before any live marketplace

- Establish legal entity, policies, privacy and data handling standards.
- Obtain permission and compliant access for any third-party platform integration.
- Implement merchant verification, buyer protections, moderation, and fraud controls.
- Conduct security audits and payment compliance reviews.
- Independently evaluate whether a token has a lawful and useful role.

No dates are promised. The phases may change or never proceed.
